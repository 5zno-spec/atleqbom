# أطلق بوم 🎈

لعبة بلالين ملونة بملف واحد (`index.html`) بدون أي مكتبات.

## طريقة اللعب
- حرّك الماوس (أو اسحب بإصبعك) للتصويب، ثم اترك/انقر للإطلاق.
- أي ٣ بالونات متجاورة أو أكثر بنفس اللون تنفجر، والبالونات المعلّقة بها تسقط.
- كل عدد من الطلقات الفاشلة ينزل صف جديد من الأعلى؛ إن وصلت البالونات إلى الخط الأحمر تخسر.
- ٥٠ مستوى تتدرج من السهل إلى الصعب. بعد المستوى ١٠ تزداد الصعوبة تدريجيًا حتى المستوى ٥٠: ألوان أكثر، صفوف أكثر في البداية، نزول أسرع للصفوف الجديدة، وتجمّع أقل للألوان المتشابهة، وخط تصويب أقصر.
- انقر على البالونة الصغيرة لتبديلها بالحالية.
- لوحة المفاتيح: ← → للتصويب، مسافة للإطلاق، X للتبديل.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا وارفع الملفين `index.html` و`README.md`.
2. من **Settings → Pages** اختر الفرع `main` والمجلد `/ (root)` ثم احفظ.
3. يظهر الرابط بعد دقيقة تقريبًا: `https://USERNAME.github.io/REPO/`

## العمل بلا إنترنت
اللعبة لا تعتمد على أي مصدر خارجي. بعد أول زيارة على GitHub Pages يحفظها المتصفح (Service Worker) وتعمل دون اتصال، ويمكن تثبيتها على الشاشة الرئيسية من قائمة المتصفح (تثبيت التطبيق / إضافة إلى الشاشة الرئيسية).
كما يمكن فتح `index.html` مباشرة من الجهاز دون إنترنت.

## معاينة مواقع التواصل
وسوم المعاينة (Open Graph وTwitter) في `index.html` تشير إلى `https://atleqbom.vercel.app/` وتستخدم الصورة `og-image.png`. عند تغيير الرابط عدّل الأسطر الثلاثة (`og:url` و`og:image` و`twitter:image`).
المنصات تحفظ المعاينة القديمة مؤقتًا، لذا أعد فحص الرابط بعد كل تعديل.

## شاشة البداية
تبدأ اللعبة بشعار `logo.png` يكبر ويصغر، وتحته شريط تقدم أزرق يمتلئ من اليمين خلال ٥ ثوانٍ، ثم تظهر شاشة «ابدأ اللعب».
